---
title: How much time the purged files are kept in the cloud?
sidebar_label: Data Retention
sidebar_position: 3
description: Information about the retention period of purged files in the cloud.
---

Purged files are kept in the cloud for a period of 30 days before being permanently deleted.

## How to recovery the data {/* #recovery */}

Execute the following command to recover the purged files:

```powershell
nimbus recover
```

## How to clean up the purged files immediately {/* #cleanup */}

Execute the following command to immediately remove the purged files:

```powershell
nimbus cleanup
```
