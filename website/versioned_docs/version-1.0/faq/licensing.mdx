---

The license can be used only on one machine at a time. If you want to use it on multiple machines, you will need to purchase additional licenses.

## What a seat includes {/* #seat */}

| Plan | Machines per Seat | Concurrent syncs |
| --- | :---: | :---: |
| Platinum | 1 | 1 |
| Gold | 1 | 1 |

## Moving a seat to a new machine {/* #transfer */}

<details>
    <summary> Step-by-step transfer </summary>

    1. Uninstall the software from the current machine.

        ```powershell
        nimbus uninstall
        ```

    2. Install the software on the new machine.

</details>
